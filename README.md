# 凯恩斯长期预期与反共识投资 Skill

> 不知道怎么提问？查看 [`可以问什么.md`](./可以问什么.md)，其中包含单股分析、介入时点、价值陷阱、多股比较、持仓体检、历史复盘和寒武纪完整提问模板。

## 快速开始

```bash
python3.11 scripts/expectation_contrarian.py \
  --symbol 600519.SH \
  --out-json /tmp/keynes_600519.json \
  --out-md /tmp/keynes_600519.md
```

批量使用指数股票池：

```bash
python3.11 scripts/expectation_contrarian.py --universe csi300 --top-n 20
```

先探测当前 PandaData 账号的接口和字段：

```bash
python3.11 scripts/expectation_contrarian.py --symbols 600519.SH --probe-only
```

凭证配置：环境变量优先，也可配置 `~/.pandadata/pandadata.env`：

```text
PANDA_USERNAME=...
PANDA_PASSWORD=...
```

## 研究逻辑

长期预期不是精确预测；市场共识在没有正式一致预期字段时只能用历史估值、公司业绩预告和市场行为做代理。Skill 首先判断企业性投资的基本面耐久性，然后分析价格隐含预期和安全边际，最后考察市场定位、催化剂与证伪条件。

低估值但盈利与现金流同步恶化的标的不会因为“便宜”自动入选。

## 输出

- JSON：指标、公式、状态、日期、评分、否决门、代理限制和 provenance；
- Markdown：中文研究报告；
- N/A：接口空、错误或不支持时保留章节并显示原因。

运行测试：

```bash
python3.11 -m pytest tests -q
```

# 凯恩斯反共识投资 Skill：可以问什么？

> 以下都是通用提问模板。将 `[股票名称/代码]`、`[股票A]`、`[股票B]`、`[股票池]` 等占位符替换为实际对象即可。

这个 Skill 是一个：

> **基本面选股 + 市场预期判断 + 预期状态择时 + 价值陷阱排查**工具。

它最适合回答的不是“明天涨不涨”，而是：

> **这家公司值得投资研究吗？市场现在对它的预期高不高？当前是不是赔率较好的研究或介入时点？什么情况说明原来的判断错了？**

# 一、最简单的问法

直接输入股票名称或代码：

```text
用凯恩斯反共识 Skill 分析寒武纪。
```

```text
用凯恩斯反共识 Skill 分析 603986.SH。
```

也可以明确分析重点：

```text
用凯恩斯反共识 Skill 分析寒武纪。区分现实基本面、市场共识代理和价格隐含预期，判断当前是过度乐观、合理定价还是过度悲观；排查价值陷阱，给出研究门控、介入节奏、催化剂和证伪条件。
```

# 二、问“现在值不值得买”

可以问：

- 寒武纪现在是便宜，还是基本面正在恶化？
- 寒武纪目前值得进一步研究吗？
- 当前价格有没有足够的安全边际？
- 这是一家好公司，但现在是不是一只好股票？
- 寒武纪现在更适合介入、等待，还是回避？
- 如果不看短期涨跌，现在的长期赔率如何？
- 当前价格反映了怎样的悲观或乐观预期？
- 不要只给买卖结论，请告诉我支持证据和证伪条件。

推荐问法：

```text
用凯恩斯反共识 Skill 分析寒武纪。判断企业性投资是否成立、当前价格是否具有安全边际，以及现在更适合进一步研究、分批观察、等待还是回避。
```

---

# 三、问“现在是不是合适的时机”

这里判断的是**预期状态择时**，不是预测明天的价格。

可以问：

- 从长期预期和市场信心看，现在是不是介入寒武纪的好时点？
- 寒武纪当前处于过度悲观、预期修复还是乐观透支阶段？
- 现在应该一次性介入、分批观察，还是继续等待？
- 市场对寒武纪的悲观预期开始修复了吗？
- 当前有哪些信号说明市场悲观可能正在结束？
- 如果现在还不是较好的时点，需要等哪些条件出现？
- 现在买入是在投资企业，还是在赌存储芯片行情和短期情绪？
- 市场流动性和融资状态是否适合承担这项投资的不确定性？

推荐问法：

```text
寒武纪基本面看起来有改善迹象，但现在是不是合适的介入时点？请从长期预期、估值、市场信心、流动性和预期修复条件分析，不要预测短线涨跌。
```

---

# 四、问“是不是价值陷阱”

这是该 Skill 最重要的用途之一。

可以问：

- 寒武纪估值下降，是反共识机会还是价值陷阱？
- 它的低估值来自市场过度悲观，还是盈利持续恶化？
- 寒武纪的问题是周期性的还是结构性的？
- 当前利润下降是库存周期，还是竞争优势已经被破坏？
- 检查寒武纪的利润、现金流和负债是否同步恶化。
- 低 PE/PB 是安全边际，还是盈利基数尚未重置？
- 市场给寒武纪较低估值是否有合理原因？
- 哪些基本面问题会触发硬否决？
- 寒武纪最危险的永久性损失来源是什么？

推荐问法：

```text
寒武纪的估值已经下降，请检查这是市场过度悲观还是价值陷阱。重点分析收入、净利润、经营现金流、资产负债、库存周期、行业竞争和审计风险，并区分周期性问题与永久性问题。
```

---

# 五、问“市场是不是过度乐观”

反共识不只是寻找被错杀的股票，也包括避免为好公司支付过高价格。

可以问：

- 寒武纪虽然是好公司，但市场是不是已经过度乐观？
- 当前价格透支了多少未来增长？
- 当前估值需要未来实现多高增长才能成立？
- 存储芯片景气复苏是否已经完全反映在价格中？
- 如果公司业绩只是符合预期，估值是否仍然有支撑？
- 当前最脆弱的市场共识是什么？
- 哪些假设一旦不成立，寒武纪可能大幅杀估值？
- 这是“好公司好价格”，还是“好公司贵价格”？

推荐问法：

```text
分析寒武纪当前是否存在预期透支。公司即使继续增长，当前价格是否已经反映了过高的收入增速、利润率或行业景气假设？请列出最脆弱的三个市场预期。
```

---

# 六、问“市场是不是过度悲观”

可以问：

- 哪些证据说明市场对寒武纪过度悲观？
- 股价下跌反映的是短期库存周期，还是长期价值损伤？
- 当前估值是否已经充分反映悲观情景？
- 寒武纪的现实是否开始改善，但市场还停留在旧的悲观预期？
- 找出寒武纪现实基本面与市场预期之间的错位。
- 收入降幅收窄、现金流改善但估值仍低，这算不算反共识机会？
- 当前价格隐含了多差的未来？
- 在悲观情景下，公司能否保持现金流并度过周期？

推荐问法：

```text
判断市场是否对寒武纪过度悲观。不要把股价下跌本身作为理由，请同时检查估值、收入利润、现金流、资产负债、行业周期和经营改善证据。
```

---

# 七、问“催化剂和证伪条件”

可以问：

- 寒武纪未来最重要的催化剂是什么？
- 下一期财报最需要看哪几个指标？
- 什么数据改善才说明预期开始修复？
- 什么情况说明反共识逻辑已经失败？
- 把寒武纪的证伪条件写成可量化阈值。
- 哪些指标应按月、按季度持续跟踪？
- 如果股价继续跌但基本面不变，应该如何处理？
- 如果股价上涨但基本面没有改善，应该如何理解？

推荐问法：

```text
为寒武纪建立反共识投资跟踪表。列出未来两个季度最重要的基本面指标、市场预期修复信号、已知催化剂和可量化证伪条件。
```

输出可能包括：

```text
跟踪指标：
1. 收入同比；
2. 净利润同比；
3. 毛利率；
4. 经营现金流/净利润；
5. 存货变化；
6. 应收账款变化；
7. 资产负债率；
8. 公司业绩预告变化；
9. 行业景气和价格周期；
10. 市场流动性与融资状态。
```

可以问：

- 用凯恩斯反共识逻辑比较寒武纪和北京君正。
- 比较寒武纪、澜起科技和江波龙，谁的预期差更有利？
- 哪家公司质量最好？哪只股票当前赔率最好？请分别回答。
- 谁的估值透支最严重？
- 谁最可能是价值陷阱？
- 按基本面耐久性、安全边际和预期状态排序。
- 比较这几只股票的催化剂和证伪条件。

推荐问法：

```text
使用凯恩斯反共识 Skill 比较寒武纪、北京君正和澜起科技。分别评价企业性投资、基本面耐久性、市场预期代理、估值安全边际、催化剂和证伪条件，并区分“最好的公司”和“当前赔率最好的股票”。
```

关键原则：

> **最好的公司，不一定是当前最好的投资。**

# 十四、不适合这样问

该 Skill 不适合：

- 明天会不会涨停？
- 下周最高价是多少？
- 哪个价格一定是底？
- 给我一只稳赚的股票。
- 什么时候一定翻倍？
- 跌了50%是不是一定可以买？
- 只按技术指标给买卖点。

可以改成：

| 不推荐 | 推荐 |
|---|---|
| 明天会不会涨？ | 当前预期是否已经过度悲观，基本面是否支持分批研究？ |
| 哪里是绝对底部？ | 当前价格是否有安全边际？继续下跌时哪些基本面条件必须成立？ |
| 直接告诉我买卖 | 给出 PASS/CAUTION/FAIL、支持证据、反证和证伪条件 |
| 跌得多是不是可以买？ | 下跌反映的是周期问题，还是永久性价值损伤？ |

# 十五、结论等级怎么理解

- **PASS：**值得进入进一步研究或分批观察，不等于自动买入；
- **CAUTION：**逻辑有部分支持，但估值、催化剂或数据覆盖不足；
- **FAIL：**存在硬否决或企业性投资逻辑已明显破坏；
- **N/A：**关键数据不足，不能形成可靠判断。

最推荐直接使用的一句话：

> **使用凯恩斯反共识 Skill 分析寒武纪，重点告诉我：它是便宜还是价值陷阱，现在是预期错位的研究/介入时点还是应该继续等待，以及什么情况会证明这个判断是错的。**
